# Common Services Centre Baghpur

A modern, responsive website for the Common Services Centre Baghpur, providing government services and computer training in rural areas.

## Features

- Professional and trustworthy design
- Mobile-first responsive layout
- Government services showcase
- Computer courses information
- Enquiry form for joining
- Testimonials and contact details
- Sticky WhatsApp button

## Tech Stack

- Next.js 15
- TypeScript
- Tailwind CSS
- Font Awesome icons

## Getting Started

1. Install dependencies: `npm install`
2. Run development server: `npm run dev`
3. Build for production: `npm run build`

## Project Structure

- `src/app/` - Next.js app directory
- `src/components/` - Reusable React components
- `src/data/` - Sample data for services, bulletins, etc.

## Customization

Update the data in `src/data/` to modify services, bulletins, testimonials, etc.
